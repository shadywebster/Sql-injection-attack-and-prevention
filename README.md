# 🔐 SQL Injection Attack & Prevention Lab

> Build. Break. Defend.  
> A complete hands-on cybersecurity project demonstrating SQL Injection exploitation and secure coding prevention techniques.

---

## 📌 Project Overview

SQL Injection (SQLi) is one of the most critical and common web vulnerabilities.  
This project is a **full-cycle security lab** where a vulnerable web application is intentionally built, attacked, analyzed, and then **securely rebuilt using industry-standard defenses**.

This repository focuses on:
- Attacker mindset (Red Team)
- Secure coding practices (Blue Team)
- Real-world impact analysis
- Professional mitigation strategies

---

## 🎯 Objectives

- Understand **why SQL Injection occurs**
- Perform **manual and automated SQLi attacks**
- Analyze **real database impact**
- Implement **secure coding prevention techniques**
- Validate security by **re-attacking the hardened app**
- Document findings like a **professional security engineer**

---

## 🧠 Learning Philosophy

> **Security is not about tools — it’s about trust boundaries.**

This project avoids copy-paste tutorials and instead follows:
- Problem decomposition
- Attacker logic modeling
- Defense-by-design principles
- Verification through re-exploitation attempts
